# Licencias de recursos incrustados

Los logos se incrustan como vectores dentro de los SVG (los SVG cargados con `<img>` no pueden pedir recursos externos).
Las marcas pertenecen a sus respectivos dueños; se usan solo para identificar las tecnologías.

| Fuente | Licencia | Logos usados |
|---|---|---|
| [simple-icons](https://github.com/simple-icons/simple-icons) (`scripts/logos/simple-icons/`) | CC0 1.0 | Python, JavaScript, TypeScript, FastAPI, React, Vite, Tailwind CSS, HTML5, CSS, scikit-learn, pandas, MySQL, PostgreSQL, Supabase, Neon, Spring Boot, Git, GitHub, Mercado Pago |
| [devicon](https://github.com/devicons/devicon) (`scripts/logos/devicon/`) | MIT | Java, C#, Oracle, AWS |
| Inter ExtraBold (`scripts/fuentes/`) | SIL Open Font License 1.1 | Solo para convertir "Mathias Castillo" a trazados en `header.svg` |

Colores: algunos logos de simple-icons se muestran en un tono de marca más claro para mantener contraste sobre fondo oscuro
(mapa `COLOR_LOGO` en `scripts/diseno.py`). La silueta del logo no se modifica.

**Logos que NO se incluyen** (ninguna de las dos fuentes los tiene): OpenAI y LinkedIn. OpenAI se menciona solo en texto
dentro de la descripción de Plataforma Estudio AI; el botón de LinkedIn va sin logo.
